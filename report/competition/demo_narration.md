# DIFI 演示讲解稿（建议口播，可按赛事时长裁剪）

> 此稿是**根据可追溯工程记录撰写的口播稿**，不是实际录制、对话或测试日志。括号里的操作提示应在录制时替换为真实画面。

## 开场

“我们的作品是面向数字中频数据互操作场景的 DIFI 1.1 FPGA 协议收发引擎。核心报文封装和解析由 Zynq-7020 的 PL 侧 Verilog RTL 实现，PS 侧主要承担配置、DMA 控制和 UDP 网络传输。我们实现了 Signal Data、Context 和 Version 三类报文的生成与解析，以及配置、时间戳、Stream ID 和异常检测等功能。它是受限 DIFI Profile 的工程实现，不声称覆盖标准中的全部可选功能。”

## 架构

“这里是两种实际使用的板级设计：封装 IP 回环设计经过 DIFI TX 和 RX 两侧，S2MM 最终取回解包后的 IQ；B5 原始报文导出设计只用 TX，S2MM 取回的是带报文头的完整 DIFI Packet。B5 由 PS 的 lwIP 和 GEM0 把原始报文作为 UDP Payload 发送给 PC，不是在 PL 内实现网络协议栈。”

## RTL 优化

“最初 Data Parser 的整包缓存未能推断为 BRAM，带来了很大的寄存器和 LUT 开销。我们将缓存改为适合同步读取的存储结构，在同一 OOC 综合口径下，LUT 从 4,023 减少到 1,516，FF 从 10,446 减少到 2,202，并使用 1 块 RAMB18。与此同时，我们保留了包含背压、报文长度和错误优先级的测试，防止资源优化破坏协议行为。”

## 性能

“在 100 MHz 理想 RTL TX→RX 回环条件下，我们连续验证了 100 包、25,600 个 IQ 样本，测得有效 IQ 吞吐率为 196.916 MB/s，平均首 IQ 延迟为 516.470 个周期。封装 IP 的布局布线结果 WNS 是 +0.411 ns。板级 Simple DMA 回环测试另行验证了 25,600 个 IQ 样本无失配。两项吞吐率的测量窗口不同，不把仿真吞吐率解释为实际 UDP 链路带宽。”

## 真实 UDP 验证

“现在展示 B5 原始报文导出流程。PC 发送 START，Zynq 接收后通过 DMA 取回 PL 生成的报文，再经 PS UDP 发送到 PC。PC 实际收到 1 个 Version、1 个 Context、20 个 Data，共 22 个 DIFI Packet，5,120 个 IQ 样本对比正确。Wireshark 保存了完整抓包，第三方开源参考工具针对两组 Stream ID 分别在 DIFI 1.1 模式下完成检查，所覆盖项目结果为 PASS。这不是官方 DIFI 认证。”

## 复现与 Skill

“除了 RTL 和板级程序，我们还将两套 Vivado BD 导出成 Tcl 快照，并在独立目录重新生成工程和 Bitstream/XSA，保留了资源、时序和构建结果。开发过程沉淀出 Vivado 重建、DMA 调试、AXI4-Stream 验证和 UDP 校验四个可复用 Skill。它们的结构和离线检查已经完成，跨项目统一实测将作为最终验收环节单独归档。”

## 结尾

“这件作品的重点不是单个报文演示，而是贯穿协议 RTL 设计、资源优化、Zynq PS/PL 协同、真实网络发送、独立参考检查及可复现构建的完整工程链路。”
