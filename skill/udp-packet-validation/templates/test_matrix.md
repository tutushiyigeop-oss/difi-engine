# UDP 验证矩阵（可复用）

| 层级 | 正向测试 | 负向/异常测试 | PASS 依据 |
|---|---|---|---|
| 物理/网卡 | PC 接收的源/目的 IP 和端口符合配置 | PC IP 绑定错误、端口占用、PC 防火墙 | Wireshark + UART + PC 日志匹配 |
| UDP 容器 | 报文数与大小符合配置 | 0 包、少包、短包、额外包、PCAP 截断 | 校验器返回 0 / 1 / 2 符合预期 |
| 应用序号 | 顺序 0..15..0（若适用） | 跳序、重复、乱序 | 按各 Stream 的实际 modulo 规则比对 |
| 数据字节序 | 字段与黄金数据一致 | 单 Word 大小端互换 | 32 位字节序独立校验 |
| Payload | 按帧比对 IQ/数组 | 故意翻转一个样本的比特 | 报告错误样本位置，拒绝 PASS |
| 第三方参考 | 原版工具按实际版本解析 | 非法 OUI/Packet Size/SID 配置 | 保存原版命令、版本、日志、独立结论 |
| 稳定性 | 多批量长时间运行 | 人为网络拥塞/丢包环境 | 待真实测试；不要凭少量样例宣称 |

### 测试前先固定口径

- 原始输入采集文件哈希（SHA-256）；如需要造错，另存副本。
- PCAP 中 UDP 包数和发送应用宣称包数是不同指标。
- UDP length **含 8-byte UDP Header**；本项目 B5 Version=44 payload B、Context=108 B、Data=1052 B。
- `udp_sendto()` 返回正常不证明另一端已经应用层处理。
- CPU/PS-lwIP/DMA/DDR 侧测量不能用于声明 PL IP 自身最高速率。
