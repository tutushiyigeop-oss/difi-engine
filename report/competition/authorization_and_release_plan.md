# DIFI 1.1 参赛授权与发布规划（报告辅助材料 v0.1）

依据 AMD 2026 自主选题赛道指南 §3.3.3.3，比赛**强烈要求**采用允许再分发的开源许可并在 GitHub/Gitee 开源，推荐 MIT/Apache-2.0；§3.3.5.1–3.3.5.4 要求完整工程、验证证据、可复现构建、Skill 与 AI 交互记录。

本项目现处于 Private 开发阶段，完整成果集中在 `feature/rtl-integration`，默认 `main` 尚非正式发布版本，根目录尚未由权利人确认 LICENSE。MIT 为优先候选，Apache-2.0 为备选，**尚未正式授权**。

规划分五关：① 开发者/学校权属确认；② 第三方 IP、DIFI/VITA 文档、认证工具与图片素材授权核查；③ 全历史和日志/抓包/聊天的隐私审查；④ 统一 Skill 验证、原始 AI 记录和板级证据归档；⑤ 选择安全公开路线、冻结评委可访问的 Tag / SHA，提交报告、源码、测试证据和演示。

仅提供合法的 Vivado BD Tcl、RTL、Vitis C、Skill 和自有测试数据；不捆绑专有工具安装包、无明确授权的第三方源码或标准出版物。完整执行依据参见 [发布工作台](../../docs/release/README.md)。本规划**不是最终验收证书或开源授权文件**。
