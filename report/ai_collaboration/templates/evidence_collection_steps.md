# 最小证据收集清单

在完整导出聊天之前，本库属于有实验验证的**技术复盘稿**，不是符合“完整提示词 + 模型回答”要求的最终对话证据包。

## ChatGPT 原始记录

- 打开包含该案例的原始聊天，复制关键对话的用户输入和模型回复，保留时间上下文。支持直接使用平台提供的对话导出/分享路径；不要伪造聊天链接、时间戳或截图。
- 附加一份未经加工的原始文本导出，若有隐私/Token，另外做一份说明了删减处的公开副本。
- 每个案例至少保存“初次输入—初版建议—运行反馈—修正版建议—真实结果”，有多少就留多少；不为凑回合捏造记录。

## Git 与命令行

在仓库根目录可以执行：

```powershell
git log --oneline --date=iso -- rtl/data/difi_data_parser.v
git show --stat 40f3c987873fbfecd79ba66369bc6176d67f815d
git show --stat a25ded8aa8817b55bd69b6dc2651a53ac16c9506
git rev-parse HEAD
```

实验输出应保留原始工具版本、设计 Top、板卡型号、代码版本、执行时间和成功/失败关键输出。最好保存 `vivado.log`/`vitis` 构建日志、UART 串口日志、截图、原始 `*.rpt`，而不只有事后总结。

## 重要边界

- 无原始错误日志的案例仍可作为“技术经验提炼”，不能作为“AI 自我纠错”的逐字实证。
- AI 的静态代码审查不是仿真、综合或上板；每个状态独立标注。
- 当前 `skill/` 四项已制作，但新工具跨项目验证还没做，统一验收时补。
